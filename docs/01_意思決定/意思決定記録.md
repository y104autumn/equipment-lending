# 意思決定記録 — equipment-lending（台帳形式）

> 件数が少ないため 1 ファイルの表で持つ。増えたら 1 件 1 ファイルへ分ける。
> 決めたその場で書く。決めた人は「オーナー」か「AI 提案→オーナー GO」かを必ず書く。

## 文脈

Figma・Claude Code・Dify を使って「画面設計 → 簡単な WEB アプリ → 業務フロー → AI の組み込み」を 1 本通す業務模擬。題材は架空の社内業務。
