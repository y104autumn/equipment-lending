# ディレクトリ構成定義 — equipment-lending

骨格: プロファイル D（複数サービス）。意思決定記録 D-7。

本体のソースは `src/` に無い。所在: `backend/`・`frontend/`。理由: 型 b（複数サービスを 1 リポに持ち、サービスごとに分ける）

| ディレクトリ | 役割 |
|---|---|
| `docs/` | 設計書（①分類型）。`01_意思決定`・`02_要求`・`03_構造`・`04_契約`・`05_振る舞い`・`07_案内`・`08_プロジェクト管理` |
| `backend/` | Spring Boot（Java 21・Maven）。パッケージ `com.example.lending` |
| `frontend/` | React＋TypeScript（Vite） |
| `scripts/` | DB 作成などの補助スクリプト（必要になった時に作る） |
