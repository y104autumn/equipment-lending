# ソースファイル一覧 — equipment-lending

> 読者: 「このファイルは何をするものか」「触っていいのか」を知りたい実装者・AI エージェント
> 読むタイミング: 見覚えのないファイルに出くわした時・`scripts/` や `tools/` にファイルを足す前
> ⛔ 概要どまりにする。引数・入出力の項目・処理手順は書かない（各ファイルの先頭のコメントが正）。

## 対象範囲と数え方

- 対象: `scripts/` の `.ps1`・`.sql`。必要になった時に足す（JIT）。
- 対象外: `backend/`・`frontend/` のアプリ本体（置き場所は `ディレクトリ構成定義.md` の宣言どおり。Maven・Vite の既定構成で用途が分かるため）、`node_modules/`・`target/` の生成物、git 管理外のファイル。
- 作業用ソース（`tools/`）は今は無い。

## 一覧

| パス | 種別 | 概要（1行） | 呼ばれ方 | 存続区分 |
|---|---|---|---|---|
| `scripts/create_db.ps1` | 単発ツール | 専用 DB を作り、接続情報を `backend/.env` に書く（D-13） | 手動（オーナーが 1 回だけ実行する） | 本流 |
| `scripts/create_db.sql` | SQL | 接続先が PostgreSQL 17／ポート 5433 であることを確かめてから、DB と接続ユーザーを作る | `create_db.ps1` から呼ばれる | 本流 |

## ⛔ 副作用のあるファイル

| パス | 何が起きるか | 安全に中身を見る方法 |
|---|---|---|
| `scripts/create_db.ps1` | PostgreSQL に DB とロールを作り、`backend/.env` を書く（既にあれば何もせず止まる） | 実行しない。テキストとして読む |
| `scripts/create_db.sql` | 同上（DB とロールを作る） | 実行しない。テキストとして読む |

## 調べ方

- 対象の列挙: `git -c core.quotepath=false ls-files scripts tools`
- ⛔ 対象を実行しない（副作用がある）
